# Additional artwork

Generated with the built-in image generation tool for this project, with transparent alpha backgrounds. The complete files are in dist/assets/.

| File | Subject prompt |
| --- | --- |
| jupiter.png | Isolated realistic Jupiter, detailed cream/tan/rust horizontal cloud bands and Great Red Spot, soft upper-left sunlight, lower-right shadow |
| uranus.png | Isolated pale cyan and sea-green Uranus, subtle atmospheric banding, soft upper-left sunlight, no conspicuous Saturn-like rings |
| pluto.png | Isolated icy Pluto with rusty tan/gray terrain and pale heart-shaped Tombaugh Regio, New Horizons inspired appearance |

All three requested a single entire round globe, cinematic photorealistic game artwork, generous transparent margins, and no stars, spacecraft or text. They are composited and resized by the game renderer; originals stay unchanged.
