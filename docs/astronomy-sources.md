# Field-note sources

The new field notes were checked against these NASA Science pages. Route distances and sizes are adjusted for the game; the illustrations are generated artwork.

- Jupiter: https://science.nasa.gov/jupiter/jupiter-facts/
- Uranus: https://science.nasa.gov/uranus/facts/
- Pluto: https://science.nasa.gov/dwarf-planets/pluto/facts/
- Oort Cloud: https://science.nasa.gov/solar-system/oort-cloud/
- Proxima Centauri: https://science.nasa.gov/asset/hubble/proxima-centauri/
- Proxima b: https://science.nasa.gov/resource/proxima-b-3d-model/

Proxima b’s appearance is imagined. All numbered Uncharted destinations are fictional exploration waypoints, identified as such in their notes.
